# 🍕 Documentație Proiect Pizzerie Bella Roma (MVP La Zi)

Documentația oficială actualizată la zi pentru aplicația web **Bella Roma Pub & Pizzerie**.

---

## 🎯 1. Prezentare Generală & Arhitectură
Aplicația este o platformă web progresivă (PWA) de gestiune a comenzilor și meniului digital în timp real pentru restaurant/pizzerie, concepută pentru performanță maximă, zero costuri fixe de găzduire și utilizare intuitivă pe orice dispozitiv (iOS Safari, Android Chrome, Tabletă, PC).

- **Frontend:** HTML5, Vanilla CSS (Stilizare Glassmorphism cu blur și fundal semi-transparent), JavaScript Moduler (ES Modules).
- **Bundler & Deploy:** Vite + Găzduire gratuită pe **Vercel** (conectat direct la repo-ul GitHub).
- **Backend & Database:** **Supabase PostgreSQL** cu abonare la evenimente în timp real (**Realtime Broadcast / WebSockets**).
- **Securitate:** Modul dedicat `js/security.js` pentru Rate Limiting, XSS Protection, Content Security Policy (CSP) și Geofencing GPS.

---

## 📱 2. Structura Paginilor & Modulelor (Arhitectură Aerisită)

Proiectul este structurat modular, fiecare pagină având responsabilități clare și un script dedicat:

### 🏢 1. `receptie.html` + `js/owner.js` — Panoul Central de Conducere
Pagina principală a conducerii restaurantului.
- **Conectare directă:** Conține butoane rapide către **Pagina Ospătar**, **Admin Meniu** și **Vezi Istoric Incurasări**.
- **Comenzi în timp real:** Recepționează instantaneu comenzile trimise de Clienți (prin QR) sau de Ospătari.
- **Afișare defalcată pe persoane:**
  - Fiecare comandă afișează preparatele grupate în casete speciale colorate.
  - Arată separat preparatele comandate la comun (**`👥 Comandă Împreună`**) sau per persoană (**`👤 Persoana 1`**, **`👤 Persoana 2`**...).
  - Calculează și afișează insigna verde **`De plată: XX.XX Lei`** pentru fiecare persoană în parte.
- **Notificări audio:** Sunet automat de alertă la sosirea unei comenzi noi.
- **Istoric Încasări:** Vizualizare total încasări zilnice și istoric comenzi finalizate.

### 📱 2. `ospatar.html` + `js/ospatar.js` — Aplicația Dedicată Ospătarilor
Interfața optimizată pentru ospătarii din sală.
- **Harta Mese în Timp Real:** Grilă interactivă cu starea tuturor meselor:
  - 🟢 **Liberă** (Masa este disponibilă pentru noi clienți)
  - 🔴/🟠 **Ocupată** (Masa are clienți și comenzi active)
- **Preluare comenzi la masă:** Ospătarul alege masa și poate adăuga preparate direct pe persoane (`Persoana 1`, `Persoana 2`...).
- **Eliberare Masă:** Buton dedicat **„Eliberează Masa”** care trece masa înapoi în starea `Liberă` când clienții achită și pleacă.

### ⚙️ 3. `admin.html` + `js/admin.js` — Administrare Meniu
Panoul de gestiune al preparatelor din meniu.
- Protejat prin autentificare PIN / sesiune de securitate.
- Adăugare preparate noi (Pizza, Băuturi, Mâncare), cu imagine, ingrediente și preț.
- Modificare și ștergere produse în timp real în baza de date Supabase.

### 🍕 4. `meniu.html` + `js/app.js` — Meniul Digital al Clientului (Scanare QR)
Interfața pe care o văd clienții după ce scanează codul QR de pe masă (`?masa=X`).
- **Detectare Masă:** Numărul mesei este extras automat din URL sau scanat direct în aplicație.
- **Panou Superior Header pentru Selecție Persoană:**
  - `👥 Comandă Împreună (Plată la Comun)` *(selectat implicit)*
  - `👤 Persoana 1`, `👤 Persoana 2` ... `👤 Persoana 6` *(pentru comenzi defalcate)*
- **Butoane de preparate dinamice:** Apăsarea pe o persoană schimba vizual butoanele din meniu în `Alegerea mea (Persoana 1)` pentru confirmare fără dubii.
- **Coș Transparent:** Coșul afișează preparatele grupate pe persoane înainte de trimitere.
- **Securitate Geofencing:** Verifică coordonatele GPS ale clientului (max 500m de restaurant) pentru a preveni comenzi false de la distanță.
- **PWA:** Poate fi adăugată pe ecranul principal al telefonului mobil ca aplicație nativă.

## 🔒 3. Modulul de Securitate (`js/security.js`)
- **XSS Protection:** Toate datele din baza de date și din form-uri sunt igienizate prin `escapeHTML()`.
- **Rate Limiting:** Previne trimiterea de comenzi spammed la intervale mai mici de câteva secunde.
- **Content Security Policy (CSP):** Restricționează sursele scripturilor și resurselor la domenii sigure (Supabase, CDNs verificate).
- **Geofencing GPS:** Calcul haversine de distanță între coordonatele clienților și restaurant.

## 🗄️ 4. Schema Bazei de Date (Supabase PostgreSQL)

### 1. Tabelul `meniu`
```sql
CREATE TABLE meniu (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nume TEXT NOT NULL,
    descriere TEXT,
    pret NUMERIC(10,2) NOT NULL,
    categorie TEXT DEFAULT 'restaurant',
    imagine_url TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### 2. Tabelul `comenzi`
```sql
CREATE TABLE comenzi (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    numar_masa TEXT NOT NULL,
    detalii_comanda JSONB NOT NULL, -- Contine Array de obiecte: [{ product, quantity, notes, customer_name }]
    total NUMERIC(10,2) NOT NULL,
    status TEXT DEFAULT 'noua', -- 'noua', 'in_preparare', 'servita'
    latitude NUMERIC,
    longitude NUMERIC,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### 3. Tabelul `mese`
```sql
CREATE TABLE mese (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    numar_masa INT UNIQUE NOT NULL,
    status TEXT DEFAULT 'libera', -- 'libera', 'ocupata'
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```
